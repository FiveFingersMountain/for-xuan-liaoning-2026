# For宣 · 数学成长工作台

针对一批真实高中数学材料设计的静态互动课程。延续“全等研究所”的方法，重点是条件、模型、解释、独立迁移和跨日复习。

- 网站：<https://fivefingersmountain.github.io/for-xuan-liaoning-2026/>
- 手机：网站内“手机接着学”，可保存访问二维码。
- 当前课程：8 个专题、34 个复核任务、67 个训练任务，含 10 道有来源的辽宁适用高考原题。
- 题源与适用省份依据可在每道真题及“使用与来源”查看；原创变式另行标注。

## 使用

先写纸面过程，再选答案。多选按正确集合判分；证明和填空采用清单自评，和自动判分分别记录。看过同源解析、用了提示或 24 小时内复做，不推进独立复习阶梯。

复习按 1、3、7、14 天安排，这是可调整的实践起点。记录保存在本浏览器，手机与电脑不自动同步，可导出 JSON 并在另一台设备合并导入。建议每周备份。

## 开发与发布

需要 Node.js。浏览器端无框架、无外部 CDN、无账户与遥测服务。

```sh
npm ci
npm run build
npm run check
npm run serve
```

编辑 `dist/`，运行 build 后将更新 `docs/` 并生成二维码。GitHub Pages 从 `main` 分支的 `/docs` 发布，不需要提交 Actions workflow。

`scripts/assemble.mjs` 是作者本地整理资料的辅助脚本，依赖未发布的私有复核资料；普通构建不运行它。已审定课程数据在 `dist/data.js`，公开克隆可以直接构建。修改数学内容时须同步题干、选项、答案、推导与来源，再执行适当验证。

`node scripts/browser-check.mjs` 用本机已安装的 Chrome 测试，先运行本地服务。未在真实微信客户端测试；网络可达性需以手机实测为准。

## 隐私与资料

原始照片保留在用户本地材料目录；旋转阅读图和私人分析位于忽略的 `.private/`，不发布。学生的本地笔记与作答不会发送到 GitHub。公开页面含重建的数学题干与针对解题步骤的教学建议，显示名称为用户指定的“宣”。

数学解析独立编写。原高考试题权利属于原权利人，按年份与题号标注可核对题源；KaTeX 为 MIT 许可，许可证随 assets/katex 分发。二维码用 qrcode 生成，构建依赖许可见各包。
